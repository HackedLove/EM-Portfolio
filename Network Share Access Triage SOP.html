SOP-104: Troubleshooting Network Share Access & VLAN Misconfigurations

Target Audience: IT Support Specialists & Help Desk Technicians

Supported OS: Windows 10 / Windows 11

1. Purpose & Scope

This standard operating procedure guides technicians through diagnosing why an office-based user cannot access network share drives, focusing on VLAN assignments and Layer 3 ACL policies.

2. Step-by-Step Troubleshooting Workflow

  1. Initial User Interview: Confirm user identity and exact error message. Ask: Are you working from your assigned desk, or have you moved to a temporary office?
  2. Endpoint IP Validation: Run ipconfig remotely to verify DHCP lease and subnet allocation.
  3. Network Reachability: Ping the default gateway, then ping the target file server's IP address. A "Destination unreachable" response points to a routing or firewall block.
  4. Switch Port & VLAN Check: Inspect the switch CLI using show interface [port] switchport to verify physical VLAN membership.
